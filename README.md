## 👨‍💻 Sobre mim

Minha formação está direcionada para **Engenharia de Software**, buscando desenvolver uma visão que vá além da implementação de código.

Ao longo da graduação, venho estudando fundamentos importantes para a construção de sistemas bem estruturados, como **Engenharia de Requisitos, Arquitetura de Software, Projeto de Software, Programação Modular, Modelagem de Software, Banco de Dados e Sistemas Operacionais**.

Atualmente também estou aprofundando meus conhecimentos em **Redes de Computadores** e **Interação Humano-Computador (IHC)**.

🎯 **Objetivo atual:** conquistar minha primeira oportunidade na área de **Engenharia de Software**, contribuindo com projetos reais e evoluindo em análise, modelagem, arquitetura, desenvolvimento e qualidade de software.

## 🧠 Engenharia de Software

```text
📋 Engenharia de Requisitos     → levantamento, análise, especificação e validação
🏗️ Arquitetura de Software      → organização, responsabilidades e estrutura de sistemas
🧩 Projeto de Software          → modelagem, modularização e definição de soluções
📐 Modelagem de Software        → UML, classes, relacionamentos e representação de sistemas
💻 Programação                  → programação modular e orientação a objetos
🗄️ Banco de Dados               → modelagem relacional, SQL e persistência de dados
⚙️ Sistemas Operacionais        → processos, memória e fundamentos de sistemas
🌐 Redes de Computadores        → fundamentos de comunicação e modelos de rede (em estudo)
🎨 IHC                          → usabilidade e desenvolvimento centrado no usuário (em estudo)
🔄 Processos Ágeis              → Scrum, Kanban, colaboração e evolução incremental
```

## 🚀 Projetos em destaque

### 🛠️ [Help Desk](https://github.com/Yuric-Viana/help-desk)

Plataforma Full Stack para **gestão de chamados**, estruturada com diferentes perfis de acesso — Administrador, Técnico e Cliente — e regras de negócio para abertura, atendimento e encerramento de tickets.

**Principais pontos:**
- controle de acesso baseado em papéis;
- gerenciamento de clientes, técnicos, serviços e chamados;
- regras de negócio e cálculo de custos;
- autenticação;
- banco de dados relacional;
- aplicação dos conceitos de modularização e organização de software.

`Next.js` `TypeScript` `PostgreSQL` `Prisma` `NextAuth.js` `Tailwind CSS`

---

### 🎬 [Moovie App](https://github.com/Yuric-Viana/moovie-app)

Aplicação Full Stack para **buscar, favoritar e avaliar filmes**, integrando uma API externa e persistindo informações do usuário.

**Principais pontos:**
- integração com a OMDb API;
- avaliações e favoritos;
- histórico de pesquisas;
- dashboard com indicadores;
- organização separada entre front-end e back-end;
- persistência com banco de dados relacional.

`React` `TypeScript` `Node.js` `Express` `SQLite` `Knex`
